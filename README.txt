Kurulum:
1) ZIP'i açın.
2) Klasör içinde cmd açın.
3) npm install
4) npm run dev
5) Tarayıcıda verilen localhost adresini açın.

Google Sheets bağlantısı:
src/App.jsx dosyasında şu satırı bulun:
const GOOGLE_SCRIPT_URL = "GOOGLE_SCRIPT_URL_BURAYA";

Buraya Google Apps Script web app URL'nizi yapıştırın.
